# Reproducibility

The goal: someone else, or the same researcher in three years, can rerun the
analysis from this repository plus the data and get the same numbers.

## Software environment

- Python dependencies live in `environment.yml` (conda) or `requirements.txt` / `pyproject.toml`. R dependencies are recorded with `renv`. When you add an import, add the package to the environment file in the same commit.
- Record tool versions that affect results (e.g. Fiji/ImageJ version, key plugin versions) in the script header or README.
- Don't rely on software that only exists on one person's machine without documenting it.

## No hidden state

- **No hard-coded personal paths** (`/Users/jane/Desktop/...`, `C:\Data\...`). Take inputs as parameters (script parameters, command-line arguments or a config file).
- Every parameter that affects results is visible: a named argument with a default, or a config file. Not a magic number buried in the code.
- Set and record random seeds wherever randomness is used.
- Scripts run from start to finish without manual steps in the middle. If a manual step is unavoidable, document it.

## Versions and changes

- Scripts and macros carry a version number (`MAJOR.MINOR.PATCH`). Bump MAJOR when results could change, MINOR for new features, PATCH for fixes that don't change results.
- Don't silently change defaults of existing analysis code. Bump the version, note it in `CHANGELOG.md`, and flag that earlier results may need re-running.
- Record analysis decisions (threshold methods, exclusion criteria, parameter choices and *why*) as dated entries in `docs/decisions.md`. Use the `log-decision` skill.
- The exact code version used for a paper, thesis chapter or report is tagged as a release (`v1.0.0`). Use the `prepare-release` skill.

## Outputs

- Results record how they were made: script name and version, parameters, date and input location. Write them into a sidecar file or the output header.
- Figures are generated by code from results files, not edited by hand afterwards in ways that change the data shown.
